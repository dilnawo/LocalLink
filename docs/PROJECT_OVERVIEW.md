
# LocalLink - Project Overview

## 1. Project Description
LocalLink is a web-based marketplace that connects customers with trusted local service providers in Sri Lanka.

## 2. Problem Statement
Customers often face difficulties finding reliable local service providers, comparing prices and arranging services conveniently.

## 3. Proposed Solution
LocalLink provides a centralized platform to discover, compare and book local services.

## 4. Objectives
- Connect customers with local service providers.
- Enable service discovery.
- Provide booking management.
- Support provider verification.
- Allow customers to submit reviews.

## 5. Target Market
Sri Lanka

## 6. Initial Launch Area
Colombo District

## 7. User Roles
- Customer
- Service Provider
- Administrator

## 8. Payment Method
Cash on Service

## 9. Technology Stack
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: MySQL
- Styling: Tailwind CSS
