
# LocalLink 🇱🇰

### Sri Lankan Local Service Marketplace

LocalLink is a full-stack web application designed to connect customers with trusted local service providers in Sri Lanka.

## Project Scope
- Target Market: Sri Lanka
- Initial Launch Area: Colombo District
- Currency: LKR
- Language: English
- Payment: Cash on Service

## User Roles
1. Customer
2. Service Provider
3. Administrator

## Main Features
- User Registration and Login
- Service Discovery and Search
- Provider Profiles
- Booking Management
- Ratings and Reviews
- Admin Dashboard

## Technology Stack
- React.js
- Node.js
- Express.js
- MySQL
- Tailwind CSS

## Project Status
Currently in Development.
